About This Project

Learn about the 3D modeling process, materials, and interaction design

3D Modeling Process

This project showcases three low-poly car models created using Blender. Each model was designed with efficiency and visual appeal in mind.

Modeling Techniques

  • Box Modeling: Started with primitive cubes and refined using extrusion, in-setting, and loop cutting
  • Clean Topology: Maintained efficient edge loops for smooth deformations
  • Low-Poly Design: Optimized polygon count while maintaining visual quality
  • Real-world Scale: Models created at proper proportions (approx. 4m length)

Model Variations

  • Car 1 (Red): Standard sedan with classic proportions
  • Car 2 (Blue): Same base model with color variation
  • Car 3 (Green): Sport variant with slightly different body shape

Materials & Textures

Each car model uses physically-based rendering (PBR) materials to achieve realistic appearance.

Material Types

  • Car Body (Metal):
    • Base Color: Various (Red, Blue, Green)
    • Metalness: 0.8 (highly metallic)
    • Roughness: 0.3 (slightly glossy)
  • Windows (Glass):
    • Base Color: Dark gray
    • Metalness: 0.9
    • Roughness: 0.1 (very smooth)
    • Transparency: Enabled with 0.8 opacity
  • Tires (Rubber):
    • Base Color: Black
    • Metalness: 0.1 (non-metallic)
    • Roughness: 0.9 (matte finish)
  • Lights:
    • Headlights: Emissive white/yellow
    • Taillights: Emissive red

Lighting Design

The 3D scene uses a multi-light setup to create a realistic garage environment.

Lighting Setup

  • Ambient Light: Soft overall illumination (intensity: 0.5)
    Purpose: Prevent completely dark shadows
  • Directional Light: Main sun-like light from above-right
    Purpose: Cast overall shadows and define shapes
  • Spot Light: Focused overhead light
    Purpose: Highlight the car from above
  • Hemisphere Light: Sky/ground color gradient
    Purpose: Add natural ambient variation

Shadow Configuration

  • Shadow map size: 2048x2048 (directional), 1024x1024 (spot)
  • Soft shadows enabled (PCFSoftShadowMap)
  • Shadow camera frustum: 10 units

Interaction Design

The application provides intuitive controls for exploring the 3D models.

Mouse Controls

  • Left-click + Drag: Rotate camera around the car
  • Scroll Wheel: Zoom in/out
  • Right-click + Drag: Pan the view

UI Controls

  • Model Selection: Switch between three car variants
  • Wireframe Mode: Toggle to view mesh structure
  • Lighting Sliders: Adjust ambient and spot light intensity
  • Camera Presets: Quick access to predefined views

Animations

  • Garage Door: Opens and closes automatically
  • Car Exit: Car drives out and returns
  • Camera Transitions: Smooth animated camera movement

Accessibility Considerations

  • Keyboard Navigation: All buttons are accessible via keyboard
  • High Contrast: UI elements use sufficient color contrast
  • Clear Labels: All controls have descriptive labels
  • Responsive Design: Works on various screen sizes
  • Alternative Views: Multiple camera angles for different needs

Technical Implementation

Frontend

  • HTML5 for structure
  • CSS3 with Bootstrap 5
  • JavaScript ES6 Modules
  • Three.js for 3D rendering

3D Tools

  • Blender for modeling
  • GLB format for export
  • PBR materials workflow
  • Three.js for rendering
